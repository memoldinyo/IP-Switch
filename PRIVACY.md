# Privacy policy

IP-Switch does not collect, store or transfer any personal data.

- **No network connections:** the application does not connect to the internet or to any other system. There is no
  telemetry, no crash reporting, no update check and no advertising.
- **Local data only:** profiles, settings, backups of adapter configurations and the log file are stored exclusively on
  your computer in `%LOCALAPPDATA%\IPSwitch`. This folder is not synchronised with roaming profiles.
- **What is stored:** the IPv4 settings you enter or capture (addresses, subnet masks, gateways, DNS servers), the
  identifiers, names and MAC addresses of your network adapters (for assigning profiles), and a technical log of
  configuration changes.
- **Removal:** uninstalling IP-Switch keeps your data by default so that a reinstallation can continue to use it. To
  remove everything, delete the folder `%LOCALAPPDATA%\IPSwitch` (the ZIP package's uninstall script can do this for
  you).
- **Exports:** profile files are only written when you export them yourself, to the location you choose.

This program will not transfer any information to other networked systems unless specifically requested by the user
or the person installing or operating it.

Questions: please open an issue at <https://github.com/memoldinyo/IP-Switch/issues>.
