## English (en-US)

**Short description**
Switch IPv4 network profiles per adapter with one click – static IP, DHCP, gateway and DNS, right from the tray.

**Description**
IP-Switch is a lightweight tray app for everyone who changes network settings regularly – technicians, administrators and engineers in the lab, on site or during PLC commissioning. Save static addresses, subnet masks, gateways and DNS servers as named profiles, assign them to your network adapters and apply them with one click from the notification area.

Before every change IP-Switch backs up the current configuration, verifies the result and automatically restores the previous settings if something goes wrong. Administrator rights are requested only for the change itself. All data stays on your PC: no account, no cloud, no telemetry. IP-Switch is open source (Apache License 2.0).

**Features**
- One-click profiles: static IP, subnet mask or prefix, gateway and DNS – or DHCP
- Assign profiles to adapters and apply them directly from the tray menu
- Overview of all network adapters with status, addresses, gateway and DNS
- Turn network adapters off and on – disabled adapters are marked with a red dot
- Backup before every change, verification and automatic rollback
- Live validation with clear messages, e.g. gateway outside the subnet or address already in use
- Import and export of profiles (JSON)
- Light and dark mode
- 8 languages: English, German, Turkish, French, Italian, Arabic, Chinese, Russian
- Private by design: no account, no cloud, no telemetry

**Keywords** ip changer, ip switcher, static ip, dhcp, network profile, network adapter, dns

**What's new in this version**
Version 1.6.4: The tray icon now reliably appears even if IP-Switch starts before the taskbar (for example at sign-in) or Windows Explorer restarts. Also in 1.6.3: turn network adapters off and on, double-click on the tray icon opens the manager, all settings in its gear menu, and Windows Network Connections (ncpa.cpl) directly from the tray and the manager.
